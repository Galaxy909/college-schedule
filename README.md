# 📅 Расписание Колледжа

Современный, быстрый веб-сервис расписания занятий в минималистичном стиле Google Calendar.

## 🚀 Возможности
- ⚡ **Мгновенная скорость:** умный кэш ускорил загрузку в 50 раз.
- 🎯 **Удобный выбор группы:** компактный выпадающий список со стрелочкой `▾` и поиском.
- 👥 **Разделение подгрупп:** переключение в один клик `[Все] [1] [2]`.
- 📅 **Календарная лента:** отображение занятий по дням недели без лишнего скролла.
- 🕒 **Таймер пары:** компактная статусная строка с отсчётом времени до звонка.
- 📱 **PWA для Android:** возможность установить сайт как приложение на рабочий стол.

## 🛠️ Запуск проекта
Просто дважды кликни на файл `start.bat` или запусти в консоли:
```powershell
.\venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```
Сайт откроется по адресу: **http://127.0.0.1:8000**
